Rainism - 우산 가져갈까?

실시간 강수 예측 서비스

외출 전 우산이 필요한지 바로 알려드립니다. 기상청 초단기강수예측 데이터를 기반으로 현재 위치의 실시간 강수 정보를 확인하세요.

주요 기능

  • 동네 외출 모드 - 현재 위치 기준 2시간 강수 예측으로 우산 필요 여부를 판단합니다.
  • 장거리 외출 모드 - 출발지와 도착지 경로의 강수 예측을 확인할 수 있습니다.
  • 실시간 데이터 - 기상청 초단기예보 API를 활용한 정확한 강수 정보를 제공합니다.

사용 방법

  1. 공공데이터포털에서 기상청 초단기예보 API 키를 발급받으세요.
  2. API 키를 입력하고 위치 접근을 허용하세요.
  3. 우산을 가져갈지 말지, 바로 확인하세요!
